# Player-facing writing

Room Royale's language makes the next action clear. It should be playful, welcoming, and readable while a player is moving. Use familiar words, short labels, and specific feedback.

Use the canonical terms in [CONTEXT.md](../CONTEXT.md). Internal names such as `Hub`, `BankedCount`, and `MechanicalThemeId` belong in code and technical documentation. Player copy uses neighborhood, delivered pieces, and theme.

## Words for the experience

| Situation | Preferred language |
| --- | --- |
| Enter a competition | Join round |
| Round phases | Shop, Style, Judge, Results |
| Deliver a cart | Checkout |
| Pieces currently on the cart | Cart space or cargo |
| Pieces already delivered | Checked out or delivered |
| Return between rounds | Back to neighborhood |
| Repeat the competition | Play again |
| Permanent decorating space | Your house |
| Buy a physical piece | Buy with a price and quantity |
| Apply an earned appearance | Apply design |
| Explain an unlock | How to earn it, followed by its actual requirement |

These are copy conventions. Their inclusion here does not mean the corresponding planned screen already exists.

## Make feedback actionable

Say what happened and what the player can do next. Tie numbers to a visible action. Examples below illustrate the intended copy style and are not claims about current UI strings.

| Situation | Example |
| --- | --- |
| Nearby piece fits | This chair uses 18 space. |
| Nearby piece does not fit | Need 18 space. You have 12 free. |
| Full cart | Cart full. Follow the green signs to checkout. |
| Checkout completes | 3 pieces checked out! |
| Furniture quantity | You own 2. 1 is placed. |
| Locked design | Win your first round to earn this print. |
| Reward progress | 80 Style Bucks closer to your skateboard. |

Use device-specific prompts beside the same action, such as E, a controller button, or Tap. Avoid instructions that assume a keyboard when the player uses touch. An unavailable action should explain the actual condition, such as space, ownership, range, or round phase.

Keep the room reveal and the player's work prominent. Describe what a player made or earned without insulting losing rooms. Rarity can name a collectible design; it does not promise automatic winning points under the approved rules.
