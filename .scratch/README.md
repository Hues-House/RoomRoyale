# Local issue backlog

This folder tracks work that comes from the public-beta audit until the project adopts a shared issue tracker.

Each issue uses a small YAML-like header with these fields:

- `title`: the issue name.
- `status`: `open`, `in-progress`, `blocked`, or `done`.
- `priority`: `P0`, `P1`, or `P2`.
- `source`: the document or acceptance check that raised the issue.

Keep one issue per file. Link evidence, scripts, and Studio test results from the issue. Do not store credentials, DataStore data, or published place files in this folder.

The P0 issues match the smallest implementation slice in [the public-beta audit](../docs/public-beta-readiness-audit-2026-08-30.md).
